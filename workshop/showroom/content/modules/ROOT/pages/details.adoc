`example.invalid` URL, stop and ask the facilitator. Do not guess an endpoint
or reuse another attendee's realm.

== What is already prepared

* A shared Keycloak server, where your account can create a realm and
  administer only the realms it creates.
* Your OpenShift namespace with the SPA frontend, BFF, proxy, and three APIs
  already deployed. The BFF and proxy wait for the realm you create.
* ConfigMaps already set to your realm's issuer, and three Secrets that hold a
  placeholder until you paste the client secrets in Module 4.

== Stop conditions

Pause and contact the facilitator if your namespace is not the one assigned
to you, the realm name is already owned by someone else, an app URL belongs to
another attendee, or the Keycloak UI offers server-wide administration. Do not
try to fix shared cluster or Keycloak settings yourself.

The legacy API activity is optional ({legacy-status}). Skipping it does not
prevent completion of the main workshop.
